## 最重要的逻辑边界

### 1. 研究对象必须改为“固定措辞下的步骤评分敏感性”

当前实验只有一种 +1 算术错误，没有比较不同错误的下游损害、最终答案正确率、完整推理轨迹或错误严重程度。若论文仍以“并非所有错误同样有害”为核心主张，现有实验不能回答该问题。

建议研究问题：在人工构造的数学中间步骤中，用 “Without any doubt” 替换 “For this step” 是否改变该 PRM 的评分，以及正确/错误目标之间的分差？可用题目：*Confidence Wording and Step-Level PRM Scores: An Exploratory Paired Study*。

### 2. A−N 是固定模板替换效应，不是一般的“自信因果效应”

同一题内的数学内容和上下文已经控制，A/N 长度也相同，这支持针对这两个具体模板的比较。但只使用一句自信模板和一句中性模板，无法排除模型对特定词语、句式或自然度的偏好。不能泛化为所有自信措辞，也不能声称模型理解或偏好“自信”。

如果未来扩展，需在看新结果前定义多个措辞模板和聚合方法；本次无需为了得到预期结论临时加模板。

### 3. “A−N 不明显”不等于“措辞完全没有影响”

正式主对比：错误步骤平均变化 +0.014320，95% 区间 [−0.001933, +0.031023]；分差缩小量 −0.002206，区间 [−0.022341, +0.018261]。两者包含零，不支持稳定的错误升分或分差缩小，也不能证明效应等于零。

审查中另作的事后探索比较发现：相对原始 B，N 的平均分差缩小约 0.038817，A 缩小约 0.036611。二者区间分别为 [0.022964, 0.054523] 和 [0.020343, 0.054024]。这说明“相对中性模板未观察到进一步缩小”和“相对原始步骤存在措辞敏感性”可以同时成立。

这些新增基线比较必须标注为**事后、未作多重比较校正的探索结果**，不能取代原先主指标。也不能据此认定统一的具体心理机制。

### 4. 样本和错误类型的适用范围较窄

50 题是有目的筛选，不是随机抽样；其中 Algebra 28 题、Prealgebra 21 题、Intermediate Algebra 1 题，题目难度为 1–3。目标都被简化为短整数计算，不能代表完整 MATH-500 难度或真实模型生成错误。

+1 是明确、方便复核的错误规则，但绝对变化相同不意味着相对误差或危害程度相同。数据里还存在三组重复目标算式：formal_024/048 的 2*12，formal_031/050 的 4*5，formal_040/043 的 9*5。它们题目上下文不同，不应在看过评分后删除，但应承认算术形式多样性有限。

统计单位采用题目是正确的；300 条输入不能当作 300 个独立样本。题级 Bootstrap 也不能消除目的抽样偏差，不能把区间解释为整个基准的随机抽样保证。

### 5. 没有排序反转，不代表 100% 分类准确率或真实场景完全稳健

观察到的是同一题内 C 分数高于 E，并没有验证统一分类阈值。以 0.5 为阈值也缺少预先校准依据。不同题的正确步骤可能得到较低分，这不自动说明标签错误；PRM 还可能受步骤呈现方式和上下文影响。

当前分数经过 sigmoid，但未验证其概率校准。论文应称为 PRM score，不能把 0.8 解释为“80% 正确概率”。没有出现排序反转，也不证明对更难错误、其他模型或不同措辞没有风险。

## 来源与复现缺口

1. 本地源文件可追踪到 SHA-256，但没有提供上游数据集 commit/revision 或独立下载比对。当前只能确认“来自用户提供、标称 MATH-500 的本地文件”，不能声称已独立认证官方快照。提交论文前应补原始下载链接和版本记录；不要改动当前冻结文件。
2. 五道开发题已隔离，不代表排除了该 PRM 训练时见过 MATH 来源题目的可能。训练数据重叠未审计，不能称这些题对模型完全未见。
3. `requirements-prm.txt` 是模型运行依赖，不包含新分析脚本需要的 matplotlib，多项版本未锁定。当前机器可以运行；全新环境尚未验证。现有审计证据已记录 Python 和关键包的实装版本。建议另建分析依赖文件及环境锁定说明。
4. 选题清单及理由已保存，但自动重建“132 中人工选 50”的筛选代码不在项目内。可以按选定 ID 重建子集，不能声称这是一套客观最优、随机或无主观判断的筛选程序。
5. `formal_50_manifest.json` 的“下一步构造/尚未检查 token”等文字是选题阶段快照，后续构造 manifest 和评分文件才代表当前阶段。它们不是现有实验未完成的证据，但论文提交材料应明确文件阶段。
6. 正式构造标记为 assistant_reviewed，未记录独立人工复核。此次又逐题审查，但仍不是独立双人标注，不应这样描述。

## 建议如何收尾

无需重跑现有 300 条实验，也不应根据结果换题。课程论文可直接围绕“固定措辞敏感性、主对比证据不足、基线比较提供补充背景”展开。先确定窄研究问题，按现有结果写方法和结果，完整交代上述局限，并补齐来源和环境记录。若没有额外时间，多模型、多措辞和其他错误类型放在未来工作。
